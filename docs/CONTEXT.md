# Project Context

## Background
This repository is for an AI Engineering Capstone project.

The student has approximately 2.5 years of previous experience as a Web Developer and is transitioning into AI/ML Engineering.

Preferred career directions:
- AI Engineer / Applied AI Engineer
- Machine Learning Engineer
- AI-oriented Software Engineer

The capstone should leverage the software/web-development background and demonstrate the ability to turn AI/ML into a usable product.

## Course Background
The course has covered Git/GitHub, Python, Pandas, NumPy, SQL, visualization, EDA, data cleaning, regression, classification, optimization, model evaluation, feature engineering, KNN, decision trees, random forest, ensemble methods, XGBoost, hyperparameter tuning, neural networks, CNNs, NLP, transformers, embeddings, prompt engineering, LangChain, RAG, AI agents, LangGraph, MCP integration, external tool calling, hypothesis testing, A/B testing, chatbot A/B testing, and time series.

## Project Philosophy
The capstone should not be a notebook-only project.

It should demonstrate:
- real-world problem solving
- data engineering
- machine learning
- software engineering
- API design
- containerization
- testing
- CI/CD
- experiment tracking
- model lifecycle
- monitoring
- drift tracking
- usable UI
- optional agentic AI

Core principle:

> One strong problem + one strong modeling story + one polished product.

## Agent Preference
The project should ideally contain an agentic component if the problem supports it.

Preferred patterns:
1. Single tool-using agent
2. Primary agent + reviewer/validator agent
3. Planner + executor + validator only if strongly justified

The agent must perform a real function such as calling an ML prediction API, querying SQL, retrieving evidence, using external APIs, explaining results, or validating another agent's output.

## Project Scope
The project duration is approximately 4 weeks and is group-based.

The project should prioritize a complete end-to-end system over excessive features.
